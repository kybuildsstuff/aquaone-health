# AquaOne Health

PureStream's cat health web app (working name). Next.js on Vercel, Supabase for data and sign-in, Claude for the assistant, Loop for billing, Resend for email.

- Decisions, setup and the build brief live in the workspace: `ky-workspace/aquaone-health/`.
- Designs: Paper, "BFCM PureStream Preparation" → "AquaOne Health · UI".
- Local setup: copy `.env.example` to `.env.local`, fill in the keys (never commit them), then `npm run dev`.
